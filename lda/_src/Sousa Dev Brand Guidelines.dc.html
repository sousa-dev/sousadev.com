01 — Logo

One mark. Three readings.

Two chevrons form an S, a pair of code brackets < >, and a D. The S chevron takes the ink of the surface it sits on; the D chevron is always Sousa Green.

ON PAPER · INK S + GREEN D
ON INK · PAPER S + GREEN D
CONSTRUCTION
Grid 120u box, 12u sub-grid.
Angle Both chevrons at exactly 45°, arms 32u.
Stroke 16u. Below 20px, step up to 18–19u.
Terminals Butt caps, mitred apexes. Never rounded.
Counter Diagonal channel between chevrons held at 21u.
Clear space One stroke width (16u) on all sides.
LOCKUPS — USE THESE, NEVER RE-SPACE BY HAND
HORIZONTAL · DEFAULT
Sousa Dev
Site header, documents, decks, signatures. Mark height = cap height × 1.6; gap = one stroke.
STACKED
Sousa Dev
Square formats: social posts, deck covers, merch, sponsorship walls.
WORDMARK ONLY
Sousa Dev
Only when the mark already appears elsewhere on the page (e.g. footer beside a header mark).
MONO · FINANCIAL & ONE-INK PRINT
Sousa Dev
Invoices, contracts, SOWs, stamps, engraving. Ink or Paper only — never green.
APP ICON · FAVICON · AVATAR
Glyph at 66% inside a tile, radius 22.5%. Green tile is the default favicon; circular files exist for LinkedIn/GitHub — never let a platform crop the square.
MINIMUM SIZES
Mark alone: 16px / 6mm. Horizontal lockup: 96px / 24mm. Stacked: 64px / 18mm.
NEVER
— Round the terminals or add an outline.
— Rotate, shear, stretch, or change the counter gap.
— Swap which chevron is green, or make both green.
— Place the mark on mid-tone photos; use Ink or Paper.
— Add gradients, glows, bevels or shadows.
— Put a tagline inside the lockup. It goes below, Plex Sans 500, +0.08em.
— Use the old grey rounded mark or the #10B43C green anywhere.
— Re-type the wordmark: always use the supplied files.

05 — Graphic & photographic style

Show the work, not the metaphor.

Everything derives from one rule already in the logo: 45° and 90° only.

The 45° pattern
2px hairlines on 12px, at 45°. Use at 4–8% opacity as a ground, full strength only in small slabs. This is the only texture we own — don't invent another.
Technical diagrams
1.5px Slate strokes, 45° elbows, exactly one green path — the active route. These replace stock illustration entirely.
Product, dark and real
Real UI with real data, flat or tilted ≤2°, cropped to one meaningful detail. No glass, no gradient stage, no floating laptops.
TEAM / WORKSPACE PHOTO
desaturated · cool cast
Photography
Real people, available light, cool grade at ~70% saturation. Eye-level, wide, subject off-centre. Banned: handshakes, hooded hackers, glowing brains, binary rain, AI-generated imagery.
Iconography
24px grid, 1.5px stroke, butt caps, mitred joins. One library (Lucide base), one weight, no fills.
99.98%
MEASURED UPTIME · 12 MONTHS
Numbers as graphics
Set large in Space Grotesk with a mono caption. Only figures we can defend.
06 — Voice

We, not I. Specifics, not adjectives.

WE SAY
"We deployed to production in 11 weeks."
"Fixed scope, documented handover, 4-hour SLA."
"Here's the architecture and why we chose it."
"Sousa Dev" — always two words, capital S and D.
WE DON'T SAY
"I" / "freelance" / "passionate about code".
"Cutting-edge", "innovative", "next-gen", "synergy".
Exclamation marks. Emoji in anything client-facing.
"SousaDev", "sousa dev", "Sousa DEV".
TONE
Direct. Short sentences. Lead with the outcome, then the method.
Confident without selling: state, don't persuade.
Technical when the reader is technical; plain when they aren't. Never condescending in either.
